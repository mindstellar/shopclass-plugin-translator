# Changelog

## 0.1.1

### Fixed
- With a child theme active, the parent theme's texts are listed and your changes to them show on the site.

## 0.1.0

### New
- Change or translate any text of Shopclass, the theme and plugins from Tools → Translator.
- Search texts and edit them, with placeholder and HTML checks.
- Download your changes as a `.po` file.
- Export the full translation of a source, or all sources as a `.zip`.
- Upload a `.po` file: add to your changes or replace them.
- Undo the last upload, and remove all changes for a source.
- Sync check after an update, with Keep mine, Use the new original and Remove mine.
- Texts are kept in `oc-content/plugin-data/translator/`, through core, theme and plugin updates.
- Translation template in `languages/translator.pot`.
